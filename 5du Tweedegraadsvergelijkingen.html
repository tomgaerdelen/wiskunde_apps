Overzicht van de vier typen

Een volledige tweedegraadsvergelijking heeft de vorm ax² + bx + c = 0. Bij een onvolledige vergelijking ontbreekt één of meer termen.

Type 1: ax² = 0

Vb. 5x² = 0

Aanpak: Deel eventueel door a. De oplossing is direct x = 0.

Type 2: ax² + c = 0

Vb. x² - 9 = 0

Aanpak: Breng de constante term naar rechts, deel eventueel door a en neem de wortel (plus en min!). Als er na verhuizing een negatief getal overblijft aan de rechterkant, zijn er geen reële oplossingen.

Type 3: ax² + bx = 0

Vb. 3x² - 2x = 0

Aanpak: Breng de gemeenschappelijke factor x buiten haakjes en stel elk deel gelijk aan 0.

Type 4: a(x - p)² + k = 0

Vb. (x - 3)² - 4 = 0

Aanpak: Breng het getal buiten het kwadraat naar rechts, neem de wortel en los op voor x.
